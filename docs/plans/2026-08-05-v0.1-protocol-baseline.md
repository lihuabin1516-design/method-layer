# v0.1 Protocol Baseline Implementation Plan

> **For agentic workers:** Execute in `D:\ccpanes-method-layer` only. Do not commit, push, create remotes, install dependencies, or modify `D:\cc-pane`.

**Goal:** Turn the draft repository into a locally verifiable, maintainable v0.1 method-layer protocol baseline that a future CC-Panes adapter can consume.

**Architecture:** Keep four standalone JSON Schema draft 2020-12 contracts (`task`, `run`, `evidence`, `handoff`) with explicit `protocolVersion` and `artifactType` discriminators. Verify the contracts with dependency-free PowerShell and checked-in positive/negative examples. Keep runtime integration advisory and outside this repository.

**Tech Stack:** Markdown, JSON Schema draft 2020-12, PowerShell 7.6.3 `Test-Json`, Python standard-library `json.tool`, Git read-only status checks.
